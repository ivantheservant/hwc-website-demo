# 聖道堂網站示範（hwc-website-demo）

中國佈道會奧克蘭聖道堂網站的示範：現有網站的內容整理版，加上三款新設計。全部是靜態網頁，用 GitHub Pages 發佈在 https://hwc.agapeinterlink.com 。

這是示範網站，並非教會的正式網站。每一頁都有 `noindex` 及頁頂的「示範網站 Demo」標示，`robots.txt` 拒絕全部搜尋引擎。教會的正式網站是 https://holywordchurch.org.nz 。

| 網址 | 內容 |
|---|---|
| `/` | 目錄頁，列出四個版本 |
| `/current/` | 現有網站的內容及結構，樸素版面，作備份對照 |
| `/a/` | 方向 A　歡迎之家：相片主導，先照顧第一次來的人 |
| `/b/` | 方向 B　莊重典雅：文字主導，襯線字配深藍 |
| `/c/` | 方向 C　教會生活入口：功能主導，卡片式 |
| `/d/` | 方向 D　當代敬拜：深色相片配超大粗體字，全螢幕選單（參考 gracecity.nz 的風格） |

## 資料夾

| 位置 | 內容 |
|---|---|
| `content\` | 唯一一份內容。`zh\` 及 `en\` 各一套，一頁一個 Markdown 檔；`site.json` 及 `downloads.json` 是中英文共用的資料。寫法見 `content\README.md` |
| `assets\` | 圖片（`img\`）、共用的 `base.css` 及 `site.js` |
| `templates\` | 五套範本：`current\`、`a\`、`b\`、`c\`、`d\`，每套一個 `template.js` 及 `style.css`；`shared.js` 是共用元件 |
| `build.js` | 建置腳本：把內容套入五套範本，輸出到 `docs\` |
| `docs\` | 建置結果，GitHub Pages 由這裏發佈。`CNAME` 及 `圖片來源.md` 是手動維護的，其餘由 `build.js` 產生，不要直接修改 |
| `tools\` | `check.js`（檢查）、`shots.js`（截圖）、`test-keyboard.js`（D 款全螢幕選單的鍵盤測試）、`prepare-images.py`（縮小圖片） |

## 修改內容的步驟

1. 修改 `content\` 內的檔案。
2. 執行 `node build.js`（只需要 Node 18 或以上，不用安裝套件）。
3. 執行 `node tools/check.js`，確認沒有問題。加上 `--external` 會同時測試全部外部連結。修改了 D 款的選單或 `assets\d.js` 時，另外執行 `node tools/test-keyboard.js`。
4. commit 並 push，GitHub Pages 會在一兩分鐘內更新。

截圖：`node tools/shots.js` 會為每一頁截取桌面（1440 闊）及手機（390 闊）的整頁截圖，存到 `..\designs\screenshots\`。這個腳本使用 `..\backup\tools\` 內已安裝的 playwright-core 及本機的 Chrome。

## 示範內容的標示

- 教會未提供的內容用示範文字，並在頁面上標明「示範內容」：整頁都是示範的，在標題下說明；只有一段是示範的，用虛線框及標籤標出。
- 「會友登入」「活動日曆」「場地預約」只放按鈕位置，連到一頁「即將推出」的說明。
- /current/ 只顯示現有網站已有的內容，不顯示示範內容。

## 與備份的差異

/current/ 的文字與 `backup\pages\` 逐行比對（`node tools/check.js`），以下是刻意不照搬的地方：

- 英文 Bulletin 只收錄最新一期（15 November 2026）。較早一期（8 November 2026）載有宣教士的近況及代禱事項，不適宜轉載到另一個公開網站，改為連回現有網站。
- Bulletin 的出席人數表是嵌入的程式，備份沒有內容，因此沒有收錄。
- 現有網站每頁頁首的圖庫橫額來源未能核實，沒有使用（見 `docs\圖片來源.md`）。
- 文件下載清單中英文共用一份資料；現有中文頁有幾個連結的文字被拆成兩段並連到不同檔案（例如「第」字連到第 52 屆），示範網站每項只保留正確的一個連結。
- 北岸事工頁的嵌入影片，備份時未能取得連結，暫時不顯示。
- 現有網站的 `/main` 與首頁內容相同，只做一頁（`/current/index.html`）。
- 可以認出兒童樣貌的相片（12 張）已移除，位置改顯示「相片從略」的方塊，或改用會址及禮堂的相片；原因及清單見 `docs\圖片來源.md`。這些相片原先已在 git 歷史內，沒有改寫歷史。
- 英文 Bulletin 四個版本（/current/、/a/、/b/、/c/）都只收錄最新一期；英文講道頁也只列最新一期的講題。`node tools/check.js` 會檢查這一點。

備份內容本身的疑點（例如中英文頁的帳號或日期不一致）沒有改動，照備份顯示，並記錄在 `..\designs\發現的問題.md`，請教會核對。

## 按決定不製作的內容

依照 `..\research\設計方向及內容建議（C3 用）.md` 內「Ivan 的決定」：常問問題併入新朋友專頁；認識信仰、私隱聲明暫不製作；宣教頁保留現有內容；年度主題只在 B 款首屏使用並標明示範內容；不做簡體中文。

## 設計的限制

四款設計只使用一般網站編輯器（Wix、Squarespace）做得到的版面：相片橫額、按鈕、卡片列、圖文並排、清單、表格、下拉選單、頁尾。沒有自訂動畫；JavaScript 只用來開關手機版選單、D 款的全螢幕選單、〔下一步〕按鈕及公告條的關閉按鈕，以及在 `/a/` 等網址按瀏覽器語言轉到中文或英文首頁。
