「相片從略」是一個淺色斜紋的方塊，標明這個位置日後會放相片。

判斷方法：逐張檢視四個版本用到的相片，凡是兒童的面容正對鏡頭而且可以辨認（包括大合照的前排），一律移除。仍然保留的相片，只有成年人，或者只拍到兒童的背影（例如獻堂禮當日在會址外的人群、崇拜時的會眾背影）。如果發現仍有遺漏，告知後會立即移除。

這些相片在移除之前，已經包含在 repo 的 git 歷史內（commit 08ee7a5 及 5177dcb）。按指示沒有改寫歷史；移除之後，示範網站不再提供這些檔案，但 GitHub 上的舊 commit 仍可以看到。

正式網站使用任何會眾相片之前，請教會確認已取得當事人（兒童則為家長）的同意。

## 三、自行繪製

- C 款首頁「快速連結」的線條圖示：由 `templates\shared.js` 內的 SVG 路徑繪製，自行設計。
- 各款的色塊、分隔線、裝飾符號：全部用 CSS 製作。

## 沒有使用的圖片

現有網站每頁頁首的橫額（備份內檔名為 `…-image-asset.jpeg` 的色牆、手提電腦、地球、聖經等相片）是圖庫相片，來源未能核實，因此四個版本都沒有使用。

## 字體及嵌入內容

- 字體由 Google Fonts 載入，全部採用 SIL Open Font License：Noto Sans TC、Noto Serif TC、Poppins、EB Garamond、Inter。
- 地圖是 Google 地圖的嵌入；宣教頁的影片是 YouTube 的嵌入；中文週報是教會 Google Drive 上的 PDF 預覽。這些內容不存放在本網站。
